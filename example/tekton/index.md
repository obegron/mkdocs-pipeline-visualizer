# Tekton catalog

Explore how the pipeline runs, what each task needs, and which steps it reuses.
These pages are generated directly from the checked-in Tekton YAML.

| Start here | What you will find |
| --- | --- |
| [Build, test, and publish](pipelines/example-pipeline.md) | Execution flow, parallel branches, final tasks, and pipeline outputs. |
| [Example task](tasks/example-task.md) | Ordered steps, parameters, workspaces, and implementation details. |
| [Reusable StepAction](stepactions/example-stepaction.md) | Container image, script, and parameter interface. |

Use **search** to find a resource or parameter. Pipeline overview links take you
to task details; task references open the reusable task documentation. Each
resource page ends with a collapsed resource definition for inspecting the YAML inline.
